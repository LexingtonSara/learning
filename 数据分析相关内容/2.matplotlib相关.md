Matplotlib是Python的绘图库,轻松地将数据图形化,并提供多样化的格式输出.
## 1. Matplotlib Pyplot
Matplotlib的Pyplot模块提供了一种直观的绘图方式,可以快速创建各种图表.
```python
import matplotlib.pyplot as plt
1. plot()函数用于绘制折线图和散点图,可以画一条或者多条线,可以指定线的颜色、样式、类型、宽度等属性.
2. scatter()函数用于绘制散点图
3. bar()函数用于绘制条形图
4. hist()函数用于绘制直方图
5. pie()函数用于绘制饼图
6. imshow()函数用于绘制图像
7. subplot()函数用于绘制子图
8. subplots()函数用于绘制多个子图
```
颜色字符:
- b: blue 蓝色
- g: green 绿色
- r: red 红色
- c: cyan 青色
- m: magenta 品红
- y: yellow 黄色
- k: black 黑色
- w: white 白色
- RGB颜色符串,多条曲线不指定颜色时,会自动选择不同颜色.
线型参数:
- '-' 实线
- '--' 虚线,由短线组成
- '-.' 点虚线,由短线和点组成
- ':' 虚线,由点组成
绘图标记:maker参数用于指定图例中标记的形状
- 'o' 圆圈
- '.' 点
- ',' 像素点
- '^' 上三角形
- 'v' 下三角形
- '<' 左三角形
- '>' 右三角形
- '1' 下三叉形
- '2' 上三叉形
- '3' 左三叉形
- '4' 右三叉形
- '8' 八边形
- 's' 正方形
- 'p' 五边形
- '*' 星号
- 'h' 六边形1
- 'H' 六边形2
- '+' 加号
- 'x' 乘号
- 'D' 菱形
- 'd' 瘦菱形
- '|' 竖线

轴标签和标题:
- xlabel()函数设置x轴标签
- ylabel()函数设置y轴标签
- title()函数设置标题
matplotlib默认不支持中文,需要设置字体才能显示中文.
```python
import matplotlib.pyplot as plt
import matplotlib.font_manager as fm

# 设置字体
font = fm.FontProperties(fname=r"C:\Windows\Fonts\simsun.ttc", size=14)

# 绘制折线图
plt.plot([1, 2, 3, 4], [1, 4, 9, 16], color='r', marker='o', linestyle='--', label='line')

# 绘制散点图
plt.scatter([1, 2, 3, 4], [1, 4, 9, 16], color='b', marker='*', label='scatter')

# 设置轴标签和标题
plt.xlabel('x', fontproperties=font)
plt.ylabel('y', fontproperties=font)
plt.title('Matplotlib 绘图示例', fontproperties=font)

# 设置图例
plt.legend(prop=font)

# 显示图形
plt.show()
```

网格线:
- grid()函数用于显示网格线
matplotlib.pyplit.grid(b=None, which='major', axis='both', **kwargs)
- b: 是否显示网格线,True显示,False不显示,默认不显示为None,如果设置**kwargs 参数,则值为True
- which: 网格线类型,major表示主刻度线,minor表示次刻度线
- axis: 网格线所在轴,x表示x轴,y表示y轴,both表示x轴和y轴,默认both
- **kwargs: 其他参数,如颜色、线宽、透明度等

```python
import matplotlib.pyplot as plt

# 绘制折线图
plt.plot([1, 2, 3, 4], [1, 4, 9, 16], color='r', marker='o', linestyle='--', label='line')

# 显示网格线
plt.grid(True, which='major', axis='both', color='gray', linestyle='--', linewidth=0.5)

# 显示图形
plt.show()
```

## 2. Matplotlib 绘制多图
Matplotlib可以绘制多个子图,并设置子图的大小、位置等属性.使用pylot中的subplots()方法和subplot()方法创建多个子图.
- subplot()方法在绘图时需要指定位置.subplot(nrows, ncols, index, **kwargs)
上述函数会将整个画布分为nrows行ncols列,然后从左到右从上到下依次编号,index参数指定第几个子图.
- subplots()方法一次可以生成多个子图,并返回一个Figure对象和一个Axes对象列表.在调用时只需要调用生成对象的axes属性即可.
-subplots(nrows=1, ncols=1, sharex=False, sharey=False, squeeze=True, subplot_kw=None, gridspec_kw=None, **fig_kw)
- nrows: 行数，默认为1
- ncols: 列数，默认为1
- sharex、sharey: 是否共享x轴、y轴，默认为False,即不共享,可设置为None、all、row、col.False或None表示不共享,all表示共享所有轴,row表示所有子图的行共享一个轴,col表示所有子图的列共享一个轴.
- squeeze: 如果为True,则返回的对象会压缩为单个子图的情况,即如果只有一个子图,则返回Axes对象,否则返回Axes对象列表.
- subplot_kw: 子图参数字典,用于设置子图的属性,如位置、大小等.
- gridspec_kw: 网格参数字典,用于设置网格的属性,如位置、大小等.
- **fig_kw: 其他参数字典,用于设置Figure对象的属性,如大小、背景色等.


bar()函数绘制条形图:
bar(x, height, width=0.8, bottom=None, *, align='center', data=None, **kwargs)
- x: x轴坐标,浮点型数组或标量
- height: 高度,浮点型数组
- width: 宽度,浮点型数组
- bottom: 底部坐标,默认为0,浮点型数组
- align: 对齐方式,center表示居中,edge表示靠边,默认center.如果对齐右边缘,可以传递负数的宽度值然后将align设置为edge.
- **kwargs: 其他参数,如颜色、线宽、透明度等.

垂直方向的条形图可以使用barh()函数绘制.bar()方法中height参数表示条形的高度,width参数表示条形的宽度,而在barh()方法中height参数表示条形的宽度,width参数表示条形的高度.

hist()函数绘制直方图:
hist(x, bins=10, range=None, density=None, weights=None, cumulative=False, bottom=None, histtype='bar', align='mid', orientation='vertical', rwidth=None, log=False, color=None, label=None, stacked=False, normed=None, *, data=None, **kwargs)
- x: 绘制直方图的数据,可以是一个一维数组或列表
- bins: 直方图的柱数,默认为10.
- range: 直方图的范围,默认为None,表示自动选择.
- density: 是否显示概率密度,默认为None,表示不显示.

pie()函数绘制饼图:
pie(x, explode=None, labels=None, colors=None, autopct=None, pctdistance=0.6, shadow=False, labeldistance=1.1, startangle=None, radius=None, counterclock=True, wedgeprops=None, textprops=None, center=(0, 0), frame=False, rotatelabels=False, *, data=None)
- x: 饼图数据,浮点型数组或列表
- explode: 突出显示的扇区,浮点型数组或列表,默认为0,表示不突出显示.值的大小表示突出显示的距离.
- labels: 饼图标签,列表,默认为None,表示不显示标签.
- colors: 饼图颜色,列表,默认为None,表示使用默认颜色.
- autopct: 格式化百分比字符串的函数,默认为None,表示不显示百分比.%d%%整数百分比,%.2f%%两位小数百分比,%.2f两位小数.
- pctdistance: 百分比标签与圆心的距离,默认为0.6.
